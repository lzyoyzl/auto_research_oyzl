# 研究 idea 写作指南

提案的读者要决定是否值得做第一个实验。读完后，他应该能用自己的话回答三个问题。**哪个问题会改变我们的认识或做法？为什么这个方法值得一试？看到什么结果会改变判断？** 到论文阶段，回到同一个问题，用实验证据回答它。提案可以留下未知，关键是能指出未知究竟在哪一步。

## 从文献里找一个值得回答的问题

读最接近的论文时，找到**承担结论的那张图、那张表或那个定理**。用自己的话复述作者比较了什么、控制了什么、证据最多支持到哪里。记录来源和章节。再挑一个会影响判断的条件，追问改变它会发生什么。

| 文献中值得追的线索 | 从线索生成候选的方法 |
|---|---|
| 强基线均分相近，但在某类样本上判断相反 | 找到两种策略预测相反的样本，构造能区分解释的对照。若只知道均分，先查分歧是否真实存在。 |
| 两篇工作结论相反 | 比对训练数据、划分、计算预算、测量单位。找出一个能单独改变的条件，预测它在哪些设置下会让结果反转。 |
| 已有方法优化的量与使用者真正关心的量不同 | 写出二者之间必须经过的环节，找一个代理量改善、最终指标仍可能不变的例子。估计剩余的改善空间。 |
| 强基线依赖某个假设或昂贵资源 | 构造该假设成立和失效的两个情形。说明谁会遇到后者，以及一个朴素替代方案为什么可能已经够好。 |

**查新要查到同一项主张。** 同时检索问题、方法别名、邻近领域的术语，沿最近邻的引用寻找更早的工作。比较双方的机制、假设、数据和已经做过的验证。若最近邻已经回答同一个问题，指出该结论；若它留下一个实质边界，说明研究这个边界能改变什么认识。“尚未找到直接验证”要附检索范围。碰到证据支持不足的地方，把它写成待诊断的前提。

**让多个候选真的有得选。** 同一现象可以产生不同问题。比如两种算法在长输入上表现分化，可以检验“训练时缺少这类样本”，也可以检验“推理时信息在固定窗口外丢失”。前者预测改变训练分布会有用，后者预测固定训练集、移动关键信息位置就会改变表现。三个候选若共用一个解释和同一个胜负实验，应合并为一个候选的实现变体。推荐时比较各自能学到什么、哪条前提最不确定，以及多快能做出决定。

## 写一份能让读者复述的提案

审核单先给查新判断与最近邻原文，之后写以下三段。可以先起草 Motivation，再回头删去 Introduction 和 Background 中用不到的铺垫。

| 段落 | 读者此时的问题 | 写法 |
|---|---|---|
| **Introduction** | 谁在什么决定上会受影响？读完这篇能多知道什么？ | 先给一个具体任务或矛盾，再交代强方法已经能做到什么，最后把剩余困难收窄为一个可回答的问题。标题和结尾都应指向这个问题。 |
| **Background** | 哪些事实是我理解下一步所必需的？ | 定义关键量、比较单位、已有机制和适用条件。在首次使用处给出处。留一个具体例子，展示后文要解释的现象。 |
| **Motivation** | 为什么这个观察会导向你选择的干预？ | 给观察依据，提出解释，说明改变哪个因素应先改变哪个可测量的量、再如何影响最终指标。写一个同样合理的竞争解释，并指出两者会在哪里作出不同预测。 |

把三段压缩成一段口头陈述，试着填一次下面的句子，再改写成自然语言：

> 在〔具体设置〕，已有方法已经能〔有依据的能力〕，但〔有后果的具体问题〕仍待解释。〔观察与来源〕使我们怀疑〔假设〕。若判断正确，保持〔控制量〕相同，只改变〔关键因素〕，应先看到〔中间现象〕，再看到〔最终指标及方向〕。〔另一解释〕对〔关键对照〕给出不同预测。若观察到〔推翻条件〕，我们就〔放弃、收窄或转向诊断〕。

不同类型的贡献可以有不同主线。算法论文说明设计选择为何应产生特定行为；测量或基准论文说明新对照能区分哪两种原本难以区分的能力；理论论文把假设、推导与边界或反例连起来；系统论文把工作负载、资源瓶颈和端到端测量连起来。能让读者更新一种判断的负结果，也可以独立成文。

## 检查逻辑闭环

把核心推导单独写成一行。**已知观察 → 待验证的解释 → 干预或对照 → 可区分的预测 → 原问题的答案。** 逐个箭头检查。给每个前提注明“原文观察”“条件推导”“本研究假设”或“本研究实测”，使读者知道哪一步还需要证据。

| 容易跳过的一步 | 反问 | 用什么补上 |
|---|---|---|
| 从文献空白跳到研究价值 | 就算回答了这个问题，谁会改变什么判断？ | 给出一种具体决策、理论分歧或测量盲点。无人关心的设置缺一张表，也可能不值得做。 |
| 从相关性跳到机制 | 哪个更简单的原因也能解释观察？ | 让两个解释面对同一批样本、近似预算和各自公平调优的基线。设计一个它们预测方向或大小不同的条件。 |
| 从方法提升跳到设计有效 | 数据、额外监督、搜索次数或算力能否单独带来同样提升？ | 让基线也获得这些资源。只移除或替换所声称有用的因素，同时测中间量和最终指标。 |
| 从局部信号跳到实际效果 | 哪一段过程会抵消增益？ | 配对测量代理量与最终目标，计入系统开销或其他群体的损失。若主张是泛化，冻结设计后用独立数据确认。 |
| 从一次零结果跳到否定假设 | 区间是否窄到足以排除有意义的效应？测量是否有机会看到它？ | 检查阳性对照、样本支持度、误差范围。执行错误、测量无力、可辨别的反证分别记录。 |

**先想最有信息量的一张图。** 写清横轴是哪项机制条件、纵轴是什么、哪两条曲线应在何处拉开或靠拢、样本单位和对照是什么。也可以是一张配对表、一个反例或一项证明。图中至少有一种合理结果会让你修改主张。如果只要分数涨了就能讲通，回去寻找能区分解释的实验。预实验优先解决最薄弱的箭头，正式实验再回答效应大小、外推范围和代价。

## 用同名实体检索演练一次

以下例子演示写法；其中的现象和结果都需要测量。

**初稿。** “同名实体很难检索，我们提出用难负例增强训练。”读者无法判断问题出在召回、重排，还是查询根本没写出区分两个实体的线索。增加任意难负例也可能有用。

**Introduction。** 用户按姓名和职业查人时，希望排在首位的是正确的人。如果正确文档和同名文档都已被召回，排序器能否利用“作曲家”等区分身份的线索？这个问题直接影响首条结果，也把研究范围限定在重排阶段。

**Background。** 固定候选文档，记录正确实体相对最强干扰项的分差，以及正确实体是否排在首位。保留有明确区分线索且标注可核查的查询；单独记录缺少线索和未召回正确文档的比例，说明结论覆盖多少实际错误。

**Motivation。** 一个待检验的解释是训练中缺少“同名但身份不符”的负例，导致姓名匹配压过职业线索。另一解释是训练时见到的负例整体太容易。两者都预测加入难负例可能提高均分。只有前一个解释进一步预测：在难度和数量相当时，专门加入同名负例，应使排序对身份线索的变化更敏感。

**决定性对照。** 保持训练预算、模型和候选池一致，比较同名负例与难度匹配的异名负例。在留出实体上构造成对查询，只替换职业线索，使正确实体随之交换，同时在无歧义查询上查副作用。先看两个实体的分差是否随线索反转，再看首位正确率是否改善。若两组都涨，且配对区间足以排除事先界定的有意义差距，就支持“一般难例已足够”。同名组在留出实体上稳定获得额外的线索响应和排序改善，才支持更具体的主张。若真实错误主要来自召回，论文应把结论限制在正确文档已入池的子集。

## 把证据写成论文

选题阶段用将来时讲预测，实验结束后用可复核的结果替换它。先写一句**当前证据允许的主结论**，包括对象、条件、比较对象与边界，再围绕读者需要解决的问题安排段落。初次发现现象、实现失败与修改方案的历史保存在研究记录中；凡会改变证据解读的探索选择、复用数据和失败对照，在论文中交代清楚。

以同名检索为例，读者自然会依次追问“实际有多少错误发生在正确文档已入池之后？”“这些错误里，排序会随身份线索改变吗？”“针对性训练比同样难的一般训练多解决了什么？”这三个问题已经给出了结果章节的顺序。第一问若显示适用范围很小，这项事实就应在引言中出现。第二问若得到否定答案，即使第三问显示平均分上涨，也要把新解释留给后续验证。

写标题时留下读者最该记住的关系。上例在提案阶段可写《同名负例能否让排序器利用身份线索？》。成稿时依证据改成有范围的发现。写摘要时用最少的背景把读者带到这个分歧，说明用哪个对照解决它，给出最有判别力的实测结果和它改变的判断。同一结果若换一个方法名仍能原封不动套在别的论文上，就再补清适用条件和比较对象。

- **引言**先解释任务与已有能力，再指出关键分歧和发现。**方法**只展开支撑主张的设计，读者应能把每个关键选择追溯到 Motivation 的一个前提。
- **结果**用读者接下来会问的具体问题排序，例如“问题有多普遍”“简单方案能解决多少”“什么时候仍有差距”。每张主图写出比较单位、对照与不确定性，再用一句话说它支持什么。用主张可追溯的原始证据填写 `claims.json`。
- **讨论**回到 Introduction 中的决定。若最终指标改善而中间预测落空，可以报告收益，机制解释仍待验证。若收益只在部分条件存在，报告其覆盖范围。若简单方法与完整方法相当且估计足够精确，写清在何种条件下简单方法已经足够。由开发集事后发现的解释保留为探索性发现，交给独立确认。

**送审前的小测试。** 请站在怀疑者的立场写一句“同样的结果也可能因为……”，定位能回答它的图、表、证明或拟做的对照。再从结论倒读到研究问题，检查中途是否换了指标、比较对象或适用人群。最后只读每段第一句，看读者能否重述贡献、依据与边界。组织段落时可以采用“语境、内容、结论”的顺序，把读者刚学到的结论变成下一段要解答的问题。[Mensh 与 Kording，Ten Simple Rules for Structuring Papers](https://doi.org/10.1371/journal.pcbi.1005619)

## 两篇可以照着拆解的原文

- **HANS，ACL 2019。** 自然语言推断模型在常规测试中答对时，“理解了句法”和“依赖词汇重叠等启发式”可能产生相同答案。作者构造让启发式与正确标签一致或冲突的样本，从而观察二者分离时模型的行为。读表 1 时可以问：删掉冲突样本后，这个基准还回答得了哪个问题？[原文及表 1](https://aclanthology.org/P19-1334.pdf)
- **KIVI，ICML 2024。** 表 1 比较键和值的量化轴，仅凭值的分布还解释不了为什么按 token 量化更好。作者在表 2 测量量化误差经过注意力加权后对输出的影响。可借鉴的是沿计算过程找到缺失的中间测量。这个案例给出了对所测配置的证据，在新模型和新负载上还需要检验适用范围。[会议记录](https://proceedings.mlr.press/v235/liu24bz.html) · [方法与表 1–2](https://arxiv.org/html/2402.02750v2)
